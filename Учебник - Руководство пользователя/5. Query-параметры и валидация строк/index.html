Query-параметры и валидация строк

FastAPI позволяет определять дополнительную информацию и выполнять валидацию для ваших параметров.

Рассмотрим это приложение в качестве примера:

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()


app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items/example1")
async def read_items(q: str | None = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

        
        
Query-параметр q имеет тип str | None, это означает, что он имеет тип str,
        но также может быть None. Значение по умолчанию действительно None, поэтому
        FastAPI будет знать, что он не обязателен.

        

            
Технические детали

            
FastAPI поймет, что значение q не обязательно, из-за значения по умолчанию None.

            
Аннотация str | None позволит вашему редактору кода обеспечить лучшую поддержку и
            находить ошибки.
